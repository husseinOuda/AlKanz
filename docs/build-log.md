# سجل النتائج والأوامر

سجل مختصر لما نُفِّذ، والأوامر التي نجحت، والأخطاء الحقيقية التي اكتشفها التحقق.

## البيئة

- Node v22.18.0 · npm 10.9.3 · Python 3.11.9 · Windows 11
- المتصفح: Chrome (يُكتشف تلقائياً؛ Edge كبديل)
- **اعتماديات المنتج: صفر.** أدوات التطوير تستخدم متصفح النظام عبر CDP.

## الأوامر التي تعمل

```bash
# التشغيل
python -m http.server 8000            # ثم http://localhost:8000

# الاختبارات
node tools/run-tests.mjs              # الكل: 123 وحدة/تكامل + 19 E2E
node tools/run-tests.mjs --unit-only  # الوحدة والتكامل فقط (~2.1 ثانية)
node tools/run-tests.mjs --headed     # بمتصفح مرئي

# اللقطات
node tools/screenshot.mjs             # سطح المكتب → screenshots/
node tools/screenshot.mjs --mobile    # الهاتف
```

## أخطاء حقيقية اكتشفها التحقق وأُصلحت

| # | الخطأ | كيف اكتُشف | الإصلاح |
|---|---|---|---|
| 1 | تعارض اسم `render` — كل شاشة تستورد `render` من `dom.js` وتصدّر `render` أيضاً | فحص بنية ES Modules | استيراد باسم مستعار `render as renderInto` في 10 شاشات |
| 2 | **الشريط الجانبي على اليسار بدل اليمين** | مقارنة اللقطة بالصورة المرجعية | في RTL العمود الأول يكون يميناً ⇒ `grid-template-columns: var(--sidebar-w) minmax(0,1fr)` وترتيب المناطق `"sidebar topbar"` |
| 3 | **أيقونات SVG تتمدّد لتملأ خلايا الجدول** | اللقطة أظهرت أيقونات تقويم بحجم 200px | لم يكن للفئة `.icon` حجم افتراضي — أُضيف `width/height: 18px` |
| 4 | الشريط الجانبي ينزلق من الجهة الخاطئة على الهاتف | لقطة الهاتف | `translateX` فيزيائي لا يتبع الاتجاه ⇒ تثبيت على `inset-inline-start` |
| 5 | **أهداف لمس 32px على الهاتف** (`.btn--sm`) | فحص E2E آلي لأحجام الأهداف | رفع `.btn--sm` وقائمة الصف والإغلاق إلى 44px داخل استعلام الهاتف |
| 6 | **إجمالي فاتورة سالب** في البيانات التجريبية | ظهر `-2.30 ر.س` في اللقطة | الخصم لم يكن مقيّداً بالمجموع الفرعي في `seed.js` (منطق التطبيق نفسه كان سليماً عبر `computeTotals`) |
| 7 | **ترتيب سجل الحركات غير محدَّد** عند تنفيذ عدة حركات في نفس الميلي ثانية | فشل متقطّع في اختبار «يبني سجل حركات متسلسلاً» | `monotonicISO()` تضمن طابعاً زمنياً متزايداً تماماً — أثر حقيقي على قابلية قراءة السجل التدقيقي |
| 8 | `import()` ديناميكي داخل معاملة IndexedDB | مراجعة الكود مقابل قاعدة MDN | نقل الاستيراد إلى أعلى الملف — انتظار وعد غير مرتبط بطلب IDB يُنهي المعاملة |
| 9 | تحذير CSP: `frame-ancestors` تُتجاهَل في `<meta>` | طرفية المتصفح | حُذفت من `<meta>` ووُثّقت كترويسة HTTP مطلوبة عند النشر |
| 10 | `@page` للطابعة الحرارية لا يمكن تبديلها بسمة على `body` | مراجعة الطباعة | ملف CSS منفصل تُبدَّل سمة `media` الخاصة به — متوافق مع CSP الصارمة |
| 11 | لقطة `fullPage` تشوّه العناصر اللاصقة | مقارنة لقطة الإعدادات بقياس فعلي (لم يكن هناك تجاوز حقيقي) | توسيع نافذة العرض مؤقتاً بدل استخدام `clip` |
