1. الموردون

### الموردون + المشتريات ⭐⭐⭐⭐⭐

هذه **أهم إضافة** بعد الوضع الحالي.

الموجود حالياً:
**منتجات → مخزون → مبيعات**

لكن لا توجد دورة شراء متكاملة:
**مورد → أمر شراء → استلام بضاعة → زيادة المخزون → تكلفة شراء → حساب المورد**

نريد إضافة شاشة:
> **الموردون**

وتشمل:
* اسم المورد
* الهاتف
* البريد الإلكتروني
* العنوان
* الملاحظات
* الرصيد المستحق
* إجمالي المشتريات
* آخر عملية شراء

ثم شاشة:
> **المشتريات**

مثل الفواتير تقريبًا:
```
المورد
رقم فاتورة المورد
التاريخ
الأصناف
الكمية
سعر الشراء
الخصم
الضريبة
الإجمالي
المدفوع
المتبقي
```

وعند اعتماد عملية الشراء مثلاً:
```
شراء 10 وحدات
       ↓
زيادة المخزون +10
       ↓
تسجيل حركة مخزون
       ↓
تحديث تكلفة المنتج
       ↓
تسجيل مديونية المورد إن كانت آجلة
```

وهذا سيحوّل النظام من برنامج **بيع ومخزون** إلى نظام أقرب إلى **ERP مصغر**.

5. تحديث تكلفة المخزون

النظام الحالي جيد، لكن نريد إضافة:
### مستويات المخزون
```
الحد الأدنى
الحد الأقصى
نقطة إعادة الطلب
```

مثلاً:
```
المخزون الحالي: 3
الحد الأدنى: 5
نقطة إعادة الطلب: 7
```

فيظهر:
> ⚠️ يحتاج إلى إعادة طلب

ثم تقرير:
### المنتجات المطلوب شراؤها
```
منتج A   الحالي 2   المقترح شراء 20
منتج B   الحالي 4   المقترح شراء 10
```

وهذه ستتصل لاحقًا مباشرة بأوامر الشراء.

6. تحديث قارئ الباركود

# قارئ الباركود بشكل أفضل ⭐⭐⭐⭐
المشروع لديه أصلًا Barcode داخل المنتجات والـPOS.

لكن نريد تطويره ليصبح:
### ماسح باركود بالكاميرا

على الهاتف:
```
[ 📷 مسح الباركود ]
```

يوجه المستخدم الكاميرا إلى المنتج، ثم:
```
Barcode
↓
البحث
↓
إضافة المنتج للعربة
```

وهذه ميزة قوية لأننا نريد أن يصبح التطبيق POS حقيقيًا على الأجهزة المحمولة.
